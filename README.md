# Tarkov Loot Prices

Native Windows prototype for an external **Escape from Tarkov PvE** price overlay.

> Work in progress. No game process modification, memory reading, DLL injection, or anti-cheat bypass. The project is not endorsed by Battlestate Games; check game rules before use.

The first development milestone is a standalone transparent Windows overlay with cached sample price data, plus an automated Windows x64 build. Real game item recognition and live flea pricing are separate subsequent milestones.
